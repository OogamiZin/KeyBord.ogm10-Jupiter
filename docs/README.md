# ogm10-Jupiter設定（マクロ・キー割当・レイヤ監視・拡張）

[← トップページに戻る](../README.md)

ogm10-Jupiter用の改造Vialです。ブラウザ（Chrome・Edge）から接続して設定する画面です。

デフォルトでJISキーボードレイアウトになっています。


**https://oogamizin.github.io/KeyBord.ogm10-Jupiter/**

## 使い方

1. パソコンの Chrome か Edge で https://oogamizin.github.io/KeyBord.ogm10-Jupiter/ を開きます（Safari と Firefox は WebHID に対応していないため使えません）。
2. 「キーボードに接続」を押し、一覧から ogm10-Jupiter を選びます。
3. 上部のボタンで「マクロ」「キー割当」「レイヤ監視」を切り替えます。右上には、接続中のキーボード名と、マクロの保存領域の使用量（例: 153 / 2988 Byte とバー）が出ます。
4. 変更は右上の「書込」でまとめてキーボードに書き込みます。まだ書き込んでいない変更があると、件数付きのオレンジ色になります（接続中とデモ中は、「デモで試す」の代わりに出ます）。
5. 終わるときは右上の「接続解除」を押します。接続を切って最初の画面に戻ります。書き込んでいない変更があるときは確認が出ます。

キーボードが手元にないときは「デモで試す」で画面の動きを確認できます。

ネットにつながらない場所で使うときは、[`index.html`](index.html) をダウンロードして、そのファイルを Chrome か Edge で開いてください。1 ファイルだけで動きます。

## できること

### マクロ

- 文章やコードをそのまま貼り付けられます。キー操作は `{LCTL+C}` のように波かっこで書きます。
- エディタ内の改行は見た目だけで、送られません。Enter は `{ENTER}` と書きます（複数行を貼ると自動で付きます）。
- `{TAB*3}`（繰り返し）、`{+LSFT}…{-LSFT}`（押したまま）、`{WAIT:200}`（待機）が使えます。
- 画面下の仮想キーボードをクリックするか、「キー入力を取り込む」で実際に押して入力できます。
- 「初期状態に戻す」で、選択中のマクロをファームウェアに書かれた初期状態（`keymap.c` の `default_macro_buffer`。初期状態が空のマクロは空）に戻せます。「書込」でキーボードに反映されます（この機能に対応したファームウェアが必要です）。
- 「個別エクスポート」で選択中のマクロだけをファイルに保存し、「個別インポート」で選択中のマクロに読み込めます。個別インポートは、個別エクスポートのファイルのほか、.vil の中のマクロを選んで取り込めます。
- 仮想キーボードは、右上の「隠す ✕」で隠し、画面下部の「仮想キーボードを出す」で戻せます（キー割当・拡張でも同じ）。
- 書き込みにはロック解除（Q と P の位置のキーを同時に長押し）が必要です。

### キー割当

- 左右のロータリーエンコーダーは、盤面の左上と右上の丸いノブ 1 つにまとめて表示します（↺ 反時計回り・↻ 時計回り・● 押し込み）。ノブをクリックすると、どれを設定するか選ぶ画面が出ます。
- 盤面でキーを選び、文字で入力するか、仮想キーボード・キー入力モード・選択式で割り当てます。Mac につないでいるときは、レイヤー 3（Mac 基本）を選んだ状態で開きます。
- 選んでいるキーの「初期設定」で、選んでいるキー 1 個だけを keymap.c の割り当てに戻せます（「書込」で反映。キー単位の初期設定の問い合わせに対応したファームウェアが必要です）。
- 「初期設定に戻す」で、全レイヤーのキー割当とエンコーダーを、ファームウェア（keymap.c）に書かれた初期設定に戻せます。Vial で設定したタップダンス・コンボ・キーオーバーライドも空に戻ります。マクロは変わりません。
- 文字は `LCTL+LSFT+K`、`LT(2,LBRC)`、`MO(1)`、`M0` のように書きます。QMK の書き方（`LCTL(KC_C)`、`(QK_LGUI|KC_L)`、`_______`）もそのまま貼れます。
- 「レイヤーをテキストで編集・レイヤー単位でのインポート」で、レイヤー全体をまとめて編集できます。`keymap.c` の `[0] = LAYOUT( … )` や、Vial の保存ファイル（.vil）からの取り込みにも対応しています。
- 変更は画面上部の「書込」を押すまで反映されません（マクロの変更もまとめて書き込みます）。書き込み後に読み戻して照合します。「変更破棄」で、書き込んでいない変更を捨ててキーボードの今の割り当てに戻せます。

### レイヤ監視

- 今有効なレイヤーのキー割り当てを、基板の配置どおりに表示します。レイヤーを切り替えると表示も追従します。
- レイヤーの用途を、盤面の左に色分けした枠と名前で表示します（Win: 0 基本・1 数字・2 機能、Mac: 3 基本・4 数字・5 機能、6: マクロ、7: ユーザー）。キー割り当ての画面でも同じ表示です。
- Win と Mac のまとまりは、名前を押すと折りたためます。最初は、つないでいる OS と逆の側が折りたたまれています。
- キーの左上の青い文字は、Shift を押しながら打つと出る文字です（JIS 配列）。
- 専用キー（LyrStat など）とマクロの説明を、盤面の下に凡例として出します。説明文は `vial.json` の `title` から読みます。
- 「小窓で表示」で、他のアプリの上に浮かせておけます。

### 全体のエクスポート・インポート

接続中は、画面上部に「エクスポート」と「インポート」が出ます。

- エクスポート: 全レイヤーのキー割当、エンコーダー、マクロ、タップダンス・コンボ・キーオーバーライドを、Vial と同じ .vil 形式で保存します。Vial の「File → Load saved layout」でもそのまま読み込めます。書き込んでいない変更も含めた、画面上の内容を保存します。
- インポート: .vil（Vial で保存したもの、このツールでエクスポートしたもの）を読み込みます。マクロも取り込みます。内容は書き込んでいない変更として入るので、確かめてから「書込」でキーボードに反映します。別のキーボード用のファイルのときは確認が出ます。
- エクスポート・インポートには、タップダンス・コンボ・キーオーバーライドも含まれます。

### 拡張（タップダンス・コンボ・キーオーバーライド・QMK 設定）

- タップダンス（8 個）: 1つのキーに「タップ」「長押」「2回タップ」「タップ→長押」の動作を持たせます。判定時間も設定できます。キー割当で TD(番号) を割り当てたキーで動きます（「一覧から選ぶ」→ タップダンス）。
- コンボ（8 個）: 入力のキー（2〜4個）を同時に押すと、出力のキーを送ります。入力はキーの位置ではなく、割り当てているキー（KC_J など）で指定します。
- キーオーバーライド（4 個）: 修飾キーとの組み合わせを別のキーに置き換えます（例: Shift ＋ BS → Del）。動かすレイヤーや、細かい発動条件も設定できます。「有効」にしたものだけ動きます。
- 各欄はクリックして選び、下の入力欄（QMK の書き方）・仮想キーボード・「一覧から選ぶ」で設定します。
- 変更は画面上部の「書込」でまとめて書き込みます。キー割当の「初期設定に戻す」を使うと、これらも初期設定（空）に戻ります。
- QMK 設定: 本家 Vial の「QMK Settings」と同じ設定です。長押しの判定時間（Tapping Term）や Permissive Hold などのタップと長押しの判定、Auto Shift、コンボの判定時間、ワンショットキー、マウスキーの速さ、Magic（Caps Lock と Ctrl の入れ替えなど）、GESC の動きを変えられます。ファームウェアが対応している項目だけが出ます。変更は「書込」で書き込み、「初期値に戻す」でファームウェアの初期値に戻せます（すぐ反映されます）。エクスポート・インポートの .vil にも含まれます。

### 仮想Jupiter（デモ中のみ）

- 「デモで試す」の間、右上の「仮想キーボード起動」で、クリックで動かせる ogm10-Jupiter を小窓に出せます（小窓に対応していないブラウザでは画面の上に浮かせます）。
- デモ用の模擬キーボードに書き込んだ割り当て・マクロ・タップダンス・キーオーバーライドで動きます。レイヤーの切り替えは、レイヤ監視にも反映されます。
- 押している間だけ押したままになります。右クリックで押したままにでき（もう一度右クリックで離す）、Shift などとの組み合わせはこれで試します。
- 「かな」キー（LNG1）でかな入力、「英数」キー（LNG2）で英数入力に切り替わり、半/全キーで交互に切り替わります。かな入力中はローマ字がひらがなになります（漢字変換はしません）。
- パソコンには何も送らず、文字は小窓の入力欄に出ます。Ctrl などとの組み合わせ、メディアキー、専用キーなどは、何を送ったかの表示だけです。コンボは試せません。

### ファームウェアの更新

- 接続中は、左上に「ファーム更新」ボタンが出ます。キーボードのファームウェアと、公開中の最新版（`docs/firmware/latest.json`）の版を比べ、新しい版があればオレンジの「ファーム更新 ●」になります。
- 「更新を始める」でロック解除のあとキーボードを書き込みモードにし、現れた「RPI-RP2」ドライブを「ドライブを選んで書き込む」で選ぶと、最新版を書き込みます。ドライブを選べないときは「ファイルを保存」して、手で RPI-RP2 にドラッグします。
- 最新版は、main のファームウェアを GitHub Actions がビルドしたときに `docs/firmware/` へ自動で公開されます。
- 更新前に、念のため設定をエクスポート（.vil）しておくことをおすすめします。

### 独自トリガ

「キー割当」と「レイヤ監視」の左のレイヤー一覧の下にある「独自トリガ」を押すと、ファームウェアに組み込んだ特殊な操作の一覧が出ます。項目にカーソルを乗せると、使うキーの位置が盤面に色付きで出ます。レイヤー番号を押すと元の表示に戻ります。

- レイヤー固定、今のレイヤーの入力（LyrStat）
- その場マクロの記録開始・再生・記録停止
- ブートローダーに入る、設定ツールを開く、書き込みのロック解除
- Mac での Alt+Tab → Cmd+Tab、接続先 OS による基本レイヤーの切り替え

一覧の内容はツールに内蔵しています。`keymap.c` の動作を変えたときは、`docs/index.html` の `triggers` も合わせて直してください。

レイヤーへの追従には、レイヤー状態を通知するファームウェアが必要です（[ファームウェアの説明](../qmk_firmware/keyboards/ogm10_jupiter/readme.md#レイヤー状態の通知表示ツール向け)）。古いファームウェアでは、レイヤー番号をクリックして手動で切り替えます。

## このフォルダについて

`docs/` の中身が、そのまま GitHub Pages で公開されます（main ブランチの `/docs` を公開元に設定）。`index.html` を更新して main に入れると、数分で公開ページにも反映されます。

## 制約

- 全角文字はマクロで送れません。
- 標準の Vial と同時に開くと、通信が混ざることがあります。片方ずつ使ってください。
