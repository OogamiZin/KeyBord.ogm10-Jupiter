ogm10-Jupiter用の改造Vialです。ブラウザ（Chrome・Edge）から接続して設定する画面です。
デフォルトでJISキーボードレイアウトになっています。

  • マクロ: M0〜のマクロをテキストで編集します。文章やコードはそのまま貼り付けられ、キー操作は {LCTL+C} のように波かっこで書きます。
  • キー割当: レイヤーごとのキーとエンコーダーの割り当てを変えます。組み合わせキーや長押しも、仮想キーボード・一覧・QMK の書き方（LT(2, KC_LBRC) など）で設定できます。
  • 拡張: タップダンス・コンボ・キーオーバーライドを設定します。
  • レイヤ監視: 今効いているレイヤーの割り当てを表示します。小窓にして、他のアプリの上に浮かせられます。

変更は右上の「書込」でまとめてキーボードに書き込みます。「エクスポート」「インポート」で、設定全体を Vial 互換ファイル(.vil)に保存・読み込みできます。
キーボードが手元にない場合は「デモで試す」で、模擬キーボードを相手に一通りの操作を試せます。

最新ファームウェア: ogm10_jupiter_vial.uf2 をダウンロード
書き込み方: キーボードを書き込みモード（RPI-RP2 ドライブ）にして、このファイルをドライブにコピーします。接続後の「ファーム更新」からも更新できます。

GitHub リポジトリ: OogamiZin/KeyBord.ogm10-Jupiter（キーボードの設計・ファームウェア・この設定ツール）

    専用キー・マクロの説明

    キーの左上の青い文字は、Shift を押しながら打つと出る文字です（JIS 配列）。薄い表示は、下のレイヤーの割り当てがそのまま効いているキーです。左上と右上の丸いノブは、エンコーダーの回転（↺ 反時計回り、↻ 時計回り）と押し込み（●）の割り当てをまとめて表示しています。

    キーボードのロックを解除

    この操作にはロック解除が必要です。解除用のキーを、バーが満タンになるまで押し続けてください。

    中止する場合はケーブルを抜き差ししてください。
